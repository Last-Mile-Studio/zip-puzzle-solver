Zip Puzzle Solver

Paste a screenshot of the Zip puzzle and get the path.

On iPhone: take a screenshot, tap the preview, choose Copy and Delete, then tap Paste. On a computer you can also press ⌘V / Ctrl+V or drop an image here.



  

    How it works
    
Everything runs in your browser; the image is never uploaded. The page finds the grid lines and any
    walls, reads each number by comparing it with reference digits, then searches for the path from 1 to the
    last number that fills every cell, discarding any branch that can no longer reach the next
    number or that cuts off part of the board.
